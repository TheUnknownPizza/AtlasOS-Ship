# AtlasOS Ship

Ship-control edition of AtlasOS for CC:Tweaked and Atlas Computer.

This repository is the authoritative online source for Ship AtlasOS installation, updates, repair, and release metadata.

Compatibility targets:
- Atlas Computer
- Standard CC:Tweaked Advanced Computer

Atlas-specific integration is additive; Ship AtlasOS must remain independently runnable on normal CC:Tweaked Advanced Computers.
